My Design Process

A structured, iterative workflow transforming ambiguity into validated, intuitive digital interfaces.

01

Discover

Contextual user interviews, stakeholder discovery sessions, requirement elicitation, and competitor benchmarking.

02

Define

Synthesizing personas, mapping user journey paths, identifying friction points, and structuring information architecture.

03

Ideate

Rapid low-fidelity sketches, user task flows, layout explorations, and iterative wireframe reviews in Figma.

04

Prototype

Building high-fidelity interactive prototypes, responsive design tokens, component libraries, and microcopy.

05

Validate

Usability audits, error validation testing, design QA with developers via Jira, and user guide preparation.
